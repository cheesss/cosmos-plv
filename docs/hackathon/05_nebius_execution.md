# 05 — Nebius execution

## What runs on Nebius

The project uses **Nebius Token Factory** (serverless inference) to call
`nvidia/Nemotron-3.5-Super-VL`. This is an NVIDIA open model (OpenMDW-1.1), and
it is the only image/video NVIDIA model in the Token Factory catalog. The calls
happen at runtime in three places:

* `scripts/hackathon/run_cosmos_diagnostics.py --backend nebius` runs batch
  diagnostics of recorded rollout videos (dev and eval splits).
* the dashboard's **"Ask Nemotron-3.5-Super-VL on Nebius"** button makes a live
  call on the selected episode.
* `scripts/hackathon/smoke_test.sh` makes one call when a key is configured.

Client: `cosmos_plv/nebius_backend.py`.

* Uses the OpenAI SDK with `base_url=https://api.tokenfactory.nebius.com/v1/`.
  If that fails, it retries once against the regional host
  `https://api.tokenfactory.us-north1.nebius.com/v1/`.
* Each episode MP4 is re-encoded to 4 fps and 320x320 and sent as a
  `video_url` data URI.
* `chat_template_kwargs.enable_thinking=false` and `temperature=0.2` are set.

Every call appends one sanitized record to `results/hackathon/nebius_calls.jsonl`:
* timestamp, requested model and served model
* Nebius request id, latency, prompt and completion tokens
* sha256 of the input video and prompt, and sha256 of the output text

The API key is read from `NEBIUS_API_KEY` or `~/.config/cosmos-plv/nebius.env`.
It is never written to logs or to the repository (`tests/hackathon/test_nebius_backend.py`
checks this).

Cosmos is not called through Nebius. The Token Factory public catalog and the
account's `/v1/models`, both checked on 2026-10-29, list no Cosmos model. Cosmos3-Edge
runs locally (see `04_cosmos_integration.md`). Nebius AI Cloud GPU instances
were not provisioned; see "Not done" below.

## Reproduce one call

```bash
source scripts/hackathon/envb.sh
python - <<'PY'
from cosmos_plv.nebius_backend import NebiusVLMClient
c = NebiusVLMClient(evidence_path="results/hackathon/nebius_calls.jsonl")
print(c.list_models()["models"])
r = c.generate("Reply with the single word: ready", max_tokens=16, tag="probe/text")
print(r.served_model, r.request_id, r.latency_s, r.raw_text)
PY
```

## Measured usage

Generated by `python3 scripts/hackathon/nebius_evidence_summary.py` from the
call log; see the section appended at the end of this document.
The cost is an estimate from the public catalog price ($0.30 per 1M input tokens,
$0.90 per 1M output tokens, checked 2026-10-29). The billed amount is whatever the
Nebius console shows.

## Not done

* **Cosmos on Nebius AI Cloud.** Deploying Cosmos3-Edge on a Nebius GPU, as a
  Serverless Endpoint or a VM running vLLM, would need billing for chargeable AI
  Cloud resources. The published L40S price is about $1.35 per GPU-hour. This was
  not authorized at the time of writing, so it was not done.
